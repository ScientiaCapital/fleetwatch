# Contributing

Contributions are welcome. The full guide is
[CONTRIBUTING.md](https://github.com/ScientiaCapital/fleetwatch/blob/main/CONTRIBUTING.md) on GitHub.

The short version:

- Bug reports with a redacted replay sample help most, then new checks, then redaction cases, then docs.
- Fleetwatch stays read-only. Don't add write tools to the `read` list or weaken the guard.
- No real device names, IDs, IPs, serials, stream keys or people's names in anything you share.
- Conventional Commits, one concern per PR, and an Evidence section showing what you ran.
- AI assistants are welcome; point yours at
  [AGENTS.md](https://github.com/ScientiaCapital/fleetwatch/blob/main/AGENTS.md).
- Security problems go to [private advisories](https://github.com/ScientiaCapital/fleetwatch/security/advisories/new),
  not issues.
